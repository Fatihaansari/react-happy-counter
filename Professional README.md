# React Counter App

A simple and responsive **Counter App** built using **React.js** and **Vite**. This project is designed as a beginner-level React project to practice components, state management, and user interactions.

## 🚀 Features

- ➕ Increase counter
- ➖ Decrease counter
- 🔄 Reset counter
- ⚛️ Built with React.js
- 🎨 Clean and responsive UI
- 📱 Works on desktop and mobile devices
- ⚡ Fast development with Vite

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Vite

## 📂 Project Setup

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Navigate to the project folder:

```bash
cd react-counter-app
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The app will be available at the local development URL provided by Vite.

## 🌐 Deployment

This project is ready to be deployed on platforms such as **Vercel** and **GitHub**.

### Build for production

```bash
npm run build
```

The production files will be generated in the `dist` folder.
